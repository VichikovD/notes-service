# Security Policy

## Поддерживаемые версии

| Версия | Поддержка |
|---|---|
| 1.1.x | ✅ |
| 1.0.x | ⚠️ только критические исправления |

## Сообщить об уязвимости

Открыто публичные issues по уязвимостям **не создаются**. Напишите на
`security@example.com` с описанием, шагами воспроизведения и оценкой влияния.
Срок первичного ответа — 3 рабочих дня.

## Автоматические проверки безопасности в CI

- **SpotBugs + find-sec-bugs** — статический анализ кода (SAST) на каждый PR.
- **OWASP Dependency-Check** — поиск известных CVE в зависимостях (порог CVSS ≥ 7 валит сборку).
- **CodeQL** (GitHub) — семантический SAST, результаты в Security → Code scanning.
- **Secret scanning** (GitHub Advanced Security / GitLab Secret Detection) — поиск утёкших секретов.

## Практики

- Секреты — только через переменные окружения / CI-secrets, никогда не в репозитории.
- Параметры БД (`SPRING_DATASOURCE_*`) задаются окружением.
- Прямой push в `main` запрещён; изменения проходят review и CI.
